# AI-Based Component Placement Error Detection in PCB Assembly

## Project status
Starter prototype / under development.

## Overview
This project compares a reference PCB image with a test image and highlights regions with visible pixel differences. It is a baseline computer-vision prototype using OpenCV. It is **not yet a trained AI model** and does not automatically prove that a highlighted region is a component-placement defect.

## Features
- Load a reference and test PCB image
- Resize test image to reference dimensions
- Convert to grayscale and reduce small noise
- Calculate absolute pixel differences
- Threshold differences and filter small regions
- Draw boxes around regions that need human review
- Save a difference mask and comparison output

## Requirements
- Python 3.9+
- OpenCV
- NumPy
- Matplotlib

Install:
```bash
pip install -r requirements.txt
```

## Run locally
```bash
python main.py
```
Enter paths to two JPG or PNG images when prompted.

## Limitations
Lighting, shadows, reflections, camera angle, rotation, and image alignment can cause false alarms. Resizing alone does not align rotated or perspective-distorted images. `PASS` means only that no region exceeded the selected thresholds.

## Testing
Run and document at least:
1. Same image as reference and test
2. Two similar images under similar lighting
3. A test image with a visible change
4. Images with different brightness
5. Images taken from different angles

Record actual observations and screenshots. Do not invent results or accuracy figures.

## Future AI extension
A genuine AI version requires a suitable labelled PCB dataset, a trained detection/classification model, and evaluation on held-out images. The report should clearly separate planned AI work from implemented and tested features.
